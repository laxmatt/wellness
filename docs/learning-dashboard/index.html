What we have learned

A private page for the owner. It runs from a file on your own disk, keeps its notes in this browser, and sends nothing anywhere.

Nothing on this site is measured yet.

There is no analytics store, no traffic data and no connected search account. The typed events in src/domain/analytics.ts describe what could be recorded; nothing calls the provider that would record them, so nothing ever has been. The four questions below therefore have no figures, and show what they would need instead of showing a zero. No figure is not the same as a figure of zero, and this page will not print the second in place of the first.

This is a local operator tool. There is no login and no route: if this ever becomes a page on the site, it needs authentication first, and that work does not exist.

Where the notes live

In this browser, on this machine, under one key in local storage. That is convenient and it is not a backup: clearing site data, another browser, or another machine all start empty. Save the register to a file and keep that file somewhere you keep things. Loading a file replaces what is here.

Nothing on this page records a visitor, and nothing here should ever hold one: no addresses, no identifiers, no referring query strings, and nothing anybody typed into the assistant or a filter.
