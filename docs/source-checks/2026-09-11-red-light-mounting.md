Both records had no `mounting` at all: no value, no note, no citation.

## Mito MitoPRO 1500+ → `["door_hang"]`

Page: https://mitoredlight.com/products/mitopro-series?variant=32084839432292

The FAQ box contents states that the 300+, 1000+ and 1500+ include an over-door
hook, steel cables and four vinyl straps. This record is the 1500+, which the
statement names, and the variant string pins the page to it.

**Not recorded: tabletop.** The same section states a tabletop stand for the
300+ only. The sentence that supplies this record's value names a different
model for that one, and taking it would transfer a fact across models.

## PlatinumLED BIOMAX 900 → `["floor_stand_optional"]`

Page: https://platinumtherapylights.com/products/biomax-rlt

The accessory descriptions state a Mobile Rack Stand and a Horizontal Stand,
both compatible with BIOMAX and both sold separately. Sold separately is
`floor_stand_optional`. Nothing states a stand ships with the panel, so `stand`
is not recorded.

**Not recorded: tabletop.** Stated for the 300 and 450 only. This record is the
900.

**Not recorded, and this one is a UI limit rather than an evidence one: the
wall bracket.** The page offers one separately, for any BIOMAX size. This
catalogue's `wall` value cannot say "sold separately": a chip reading "Wall"
would tell a shopper the panel comes ready to mount. The evidence is kept here
and the value waits for a way to say optional about it, the way
`floor_stand_optional` already does for stands.

Identity, price and images are untouched. This is the ninth-generation 900 and
the 1500+ variant, as before.
