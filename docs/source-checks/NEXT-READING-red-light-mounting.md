# Next reading: mounting, on four red-light panels

Not a reading. An inventory, so the next one does not start by rediscovering
what is already here.

Four of eight red-light panels hold nothing for `mounting`, which is why every
mounting chip leaves half the category unplaced and why "Door hang", "Stand" and
"Floor stand optional" each show four products as Needs confirmation in the fit
section.

`mounting` is a list. This category defines five values: `stand`, `door_hang`,
`wall`, `tabletop`, `floor_stand_optional`. It is filterable and it is not a
scoring criterion, so a figure arriving moves completeness and the filter, and
moves no score and no badge.

## What a reading needs to answer

What the maker states ships with the panel, and what it offers separately. The
four records that do hold mounting show how narrow the distinction is:

- **Bon Charge Max**: `["door_hang"]`. The page lists a door mount, a pulley,
  cables, goggles and a cord as included. No stand is offered, so none is
  recorded.
- **Hooga PRO1500**: `["door_hang", "floor_stand_optional"]`. The page includes
  a door mount and hanging kit, and says mobile stands are sold separately.
  Sold separately is `floor_stand_optional`, not `stand`.
- **Mito MitoMIN 2.0**: `["stand"]`. A built-in tabletop kickstand. No other
  mounting is stated and none is recorded.
- **Hooga HG300**: `["stand"]`, still relayed from a search summary rather than
  read. Worth re-reading on the same pass if the page is open.

So the question is not "can it be hung" but which of the five values the maker's
own words support, and a panel can hold several. An included door kit is
`door_hang`. A built-in kickstand is `stand`. A stand sold separately is
`floor_stand_optional`. Wall brackets are `wall`. A desk stand is `tabletop`.

## What not to do with it

A photograph of a panel on a stand is not a statement that a stand is included.
Neither is a lifestyle image, nor a stand sold on the same site under a
different product. If the page shows an accessory without saying it ships with
this panel, that is `floor_stand_optional` at most, and nothing at all if it is
not named as compatible.

Absence still costs completeness rather than becoming a value. A page that lists
what is in the box and does not mention a stand has not said there is no stand,
unless it states the box contents exhaustively, which is the distinction OLIPOP's
caffeine page settled earlier today.
