# Source checks

One file per reading of a primary source. Each names the page, when it was
read, who read it, what it stated, what was recorded, what was not, and what
the reading did to the rankings.

## Who reads

Codex reads, with its own web tool, and hands the reading over. This
repository's container cannot reach the public internet: outbound HTTPS is
blocked by policy and returns 403. Nothing here has ever fetched a
manufacturer page, and no file may say it did. Every citation says "read by
Codex and supplied to this repository; not fetched here".

## The rules these files apply

**Recorded is not verified.** A URL in a record says somebody once wrote it
down. It does not say anybody looked.

**A source URL is not a reading.** Citing a page nobody opened is worse than
citing nothing, because it looks like evidence.

**Cite the page that states the fact.** The Cure record cited a variety pack
page for a single flavour's potassium. A different product's page cannot state
this product's figures, whatever it says.

**Conflicts are recorded, not resolved.** Two figures from the same maker on
the same day are marked disputed and both are kept. Picking the one that
scores better is not adjudication.

**Derived money follows its basis.** Change the price and every figure computed
from it is recomputed or withdrawn. A derived figure that disagrees with its
own basis is a wrong number with a citation.

**Silence is not a zero.** A label that does not mention caffeine does not say
there is none. Missing stays missing, and it costs the record completeness.

**Scoring policy is not a product fact.** A five-year cap, a lifetime mapping,
a tier threshold: these live in the category definition. Writing one into a
product as if the maker had claimed it is the mistake this folder has caught
twice.

**Absent from the handoff does not mean absent from the source.** A reading
reaches this repository as a summary, and a summary omits things. When a
handoff does not mention a figure, the record says nothing about it. It must
never say the page states nothing about it, and it must never call an existing
recorded value invented on that basis. Only the reader can say what the page
did not state. This rule exists because the Cure entry broke it: an omitted
line in a handoff became a written claim that the page stated no mixing
volume, and the page did state one.

**A merchant listing is a merchant's claim.** So is a marketplace's stock
status. Record it as one, with its URL, and do not promote it to a fact about
the maker or the company.

**A reading is not permission.** Opening a page grants no right to its images
and verifies no health claim printed on it.
